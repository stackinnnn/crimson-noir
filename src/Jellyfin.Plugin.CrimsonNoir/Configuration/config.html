Crimson Noir

A black theme that shows artwork backdrops, with an accent colour picker. Each person picks their accent in the profile menu (top right).

Adds Crimson Noir's styles and script to Jellyfin Web. Turn off to go back to the stock look without uninstalling.
Makes the pause screen, paused player bar and Playback Info work in Jellium Desktop (which plays video through mpv). Does nothing in other clients.

Changes apply after a page reload (Ctrl+Shift+R).
